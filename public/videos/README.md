# Video Background

## Required Video

Place your gym scanning/pay-per-day video here:

**File:** `gym-scanning.mp4`

**Recommended Specifications:**
- Format: MP4 (H.264 codec)
- Resolution: 1920x1080 (Full HD) or higher
- Duration: 10-30 seconds (will loop)
- File size: Keep under 10MB for optimal performance
- Content: Should show gym scanning, QR code scanning, or pay-per-day usage

## Video Content Ideas

The video should showcase:
- User scanning QR code at gym entrance
- Pay-per-day payment process
- Gym access/check-in
- Multiple fitness activities (gym, yoga, etc.)

## Alternative

If you don't have a video yet, the site will show an animated gradient fallback. You can add the video later by placing `gym-scanning.mp4` in this directory.
